Игра «Угадай число» 🎮

Игра, где компьютер загадывает число от 1 до 973, а ты угадываешь.
С ней вам точно не будет скучно, ведь чисел много. 

Как играть пошагово 👇
1. Запусти `mygame.py`
2. Введи число
3. Следуй подсказкам
4. Напиши `exit`, если захотите выйти
